# Customer Segmentation

## Project Overview
در این پروژه، یک دیتاست مربوط به مشتریان یک بانک مورد بررسی قرار گرفت. این دیتاست شامل اطلاعاتی مانند سن، جنسیت، میزان واریزی و میزان مخارج مشتریان است.

هدف پروژه، بررسی و گروه‌بندی مشتریان با استفاده از الگوریتم‌های مختلف Clustering است.

## Data Preprocessing
- بررسی اولیه دیتاست و آشنایی با ساختار داده‌ها
- حذف ستون `CustomerID` به دلیل ایجاد تداخل در فرایند آموزش مدل
- نرمال‌سازی داده‌ها

## Clustering Algorithms

### 1. K-Means
الگوریتم K-Means با تعداد کلاسترهای مختلف اجرا شد. برای بررسی بهتر عملکرد مدل و مشاهده نحوه تقسیم‌بندی داده‌ها، نمودارهای مربوط به تعداد کلاسترهای مختلف رسم شدند.

### 2. Hierarchical Clustering
الگوریتم Hierarchical Clustering نیز برای گروه‌بندی مشتریان استفاده شد. علاوه بر نمایش نتایج خوشه‌بندی، نمودار Dendrogram برای بررسی ساختار خوشه‌ها رسم شد.

### 3. DBSCAN
در مرحله آخر، الگوریتم DBSCAN برای خوشه‌بندی داده‌ها مورد استفاده قرار گرفت.
